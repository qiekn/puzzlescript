## QuickStart


```bash
# Make sure `git-lfs` and `nodejs` installed
node -v
git lfs -v

# Crucial: Initialize LFS
# NOTE: You only need to run this ONCE per computer globally.
# If you have run this command on this machine before, you do not need to run it again.
git lfs install
```

```bash
git clone https://github.com/qiekn/puzzlescript.git
npm install
npm run dev
```


## Commands

```bash
npm run dev
npm run build
npm start
```
